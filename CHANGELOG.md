# Changelog

## 4.0.0

- One SSR-safe, dependency-free core with real ESM/CommonJS/browser exports.
- Preserve original DOM nodes and event handlers; idempotent initialization and teardown.
- Responsive grid faces, reversible transform transitions, fade and scale effects.
- Frame-batched pointer tilt, touch tap, keyboard controls, inert hidden faces and live reduced motion.
- Typed flip/toggle/update/state methods and change events.
- React hook, Vue 3 directive and Svelte action using existing framework-owned faces.
- Model-independent agent tool schema and allowlisted command executor with plain-text content.
- Reproducible build, automated lifecycle tests, type checks, CI and npm release workflow.

Breaking: jQuery registration removed; generated face classes replaced by data attributes;
framework integrations use existing direct-child faces; npm exports now distinguish ESM and CJS.
